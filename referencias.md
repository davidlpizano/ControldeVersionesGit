## Referencias

- **[Documentación oficial de Git (Git Book)](https://git-scm.com/book/es/v2):** Guía completa de referencia y comandos oficiales de Git.
- **[GitHub Docs](https://docs.github.com/es):** Tutoriales, guías y buenas prácticas sobre gestión de repositorios, branches y colaboración.
- **[Markdown Guide](https://www.markdownguide.org/):** Especificaciones de sintaxis y buenas prácticas para la creación de archivos README y documentación en formato Markdown.
- **[Atlassian Git Tutorial](https://www.atlassian.com/es/git/tutorials):** Artículos y flujos de trabajo sobre arquitectura de ramas y trabajo en equipo con Git.
